Teaching

MSc courses and student supervision at Hochschule Bonn-Rhein-Sieg.

I have been a lecturer in the MSc Autonomous Systems programme at Hochschule Bonn-Rhein-Sieg since 2020. In most courses, students build and demonstrate a working system.

Courses (MSc)

  • Fundamentals of AI for Robotics
  • Explainable Machine Learning
  • Software Engineering for Robotics
  • Autonomous Systems Development Lab
  • Scientific Experimentation and Evaluation
  • Introduction to Scientific Working
  • Planning, Writing, and Presenting Scientific Projects
  • R&D Colloquium

Supervision

Supervision each semester covers several MSc students and student teams:

  • Software Development Projects. Semester-long team projects that deliver a working robotic system, from design to a live demo on real hardware (for example a Toyota HSR service robot, a TurtleBot3 fleet, or an xArm6 manipulator).
  • Explainable Machine Learning projects. Shorter projects that apply symbolic and neural explanation methods to robotics tasks.
  • Research and Development projects. Individual research projects, some carried out with external partners.
  • Theses. Topics in robotics and explainable AI.

Selected Supervised Work

  • MSc thesis. A Model-Based Approach for Fault Detection and Diagnosis in Robotics using Inductive Logic Programming, 2024.
  • R&D project. Clinical Human Activity Recognition using Wearable IMU Sensing, 2025.
  • R&D project. Analysing and Adapting XAI Methods for Automatic Speech Recognition, with Fraunhofer FKIE, 2025.
  • R&D project. Prototype Implementation of Snapshot Algorithms for Distributed Robotic Systems, 2020.
  • Course project. Learning Interpretable Scheduling Policies for Online Multi-Robot Task Allocation via Inductive Logic Programming, Explainable Machine Learning, published at PlanRob 2026.
  • Ongoing R&D projects. Fault detection with logic description languages, task allocation in heterogeneous multi-robot systems, multi-robot cyber security, ILP for robotic signal analysis, and software tools for multi-agent robot systems.
